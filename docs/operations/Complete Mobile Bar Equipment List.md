# Pour Social Complete Mobile Bar Equipment List

This document supports event setup, equipment purchasing, and staff packet preparation.

## Core setup

### Portable bar

Start with at least one portable bar station.

Options:

- folding bar
- rustic wood bar
- custom mobile bar
- future bar trailer upgrade

Typical starting cost:

| Item | Estimate |
| --- | ---: |
| Portable folding bar | $200–$600 |
| Rustic wedding bar | $500–$1,500 |
| Bar trailer later upgrade | $3,000–$10,000 |

## Bar tools

Recommended starter quantities:

- 3–4 Boston shaker sets
- 3–4 double jiggers
- 3–4 long bar spoons
- 2–3 muddlers
- 3–4 Hawthorne strainers
- 1–2 fine mesh strainers
- 3–4 wine keys
- 3–4 bottle openers
- 20–30 pour spouts

## Ice and cooling

- 2 ice bins
- 2 ice scoops
- 2 large coolers
- backup cooler space for high-volume events

Ice planning should follow the canonical assumption:

```text
1–1.5 lb ice per guest
```

## Prep and garnish equipment

- cutting boards
- bar knives
- citrus press
- garnish trays
- squeeze bottles
- food-safe batching containers
- labels and marker tape

## Service items

- cocktail napkins
- disposable cups if needed
- straws or stir sticks
- bar towels
- trash bags
- sanitizer bucket
- table covers

## Storage and transport

- 3–5 storage totes
- folding tables
- hand truck / dolly
- tablecloths
- lighting for evening events

## Uniform and staff presentation

Bartenders should follow a consistent Pour Social presentation standard:

- black shirt
- black pants
- apron
- clean professional appearance
- event packet reviewed before arrival

## Optional premium upgrades

- branded bar sign
- custom menu board
- signature cocktail display
- cocktail smoke gun
- upgraded bar lighting
- branded garnish picks or napkins

## Estimated startup equipment cost

Basic startup equipment for most events up to about 100 guests:

| Category | Estimate |
| --- | ---: |
| Portable bar | $400 |
| Bartending tools | $200 |
| Ice and coolers | $150 |
| Pour spouts and accessories | $50 |
| Cups / basic glassware | $80 |
| Sanitation supplies | $80 |
| Tables and transport | $150 |

Estimated total:

```text
$1,000–$1,200
```

Minimum starter kit:

- portable bar
- 3 shaker sets
- 3 jiggers
- 2 strainers
- 2 muddlers
- 2 ice bins
- 2 coolers
- 20 pour spouts
- garnish tray
- cutting board and knife
- 20 bar towels

Minimum startup range:

```text
$800–$1,000
```

## Scaling for larger events

For events over 150 guests, consider:

- second portable bar
- additional bartender tools
- additional ice bins
- additional coolers
- more cups/glassware
- second garnish station
- backup staff packet
