# Pour Social Bottle Allocation Templates & Shopping Lists

This document provides event alcohol allocation templates using the canonical Pour Social planning assumptions.

Canonical assumptions live in:

`docs/automation/ALCOHOL_PLANNING_ASSUMPTIONS.md`

## Core formulas

```text
estimated_drinks = drinking_guests × service_hours × 0.95
liquor_bottles = cocktail_drinks ÷ 14, rounded up
wine_bottles = wine_glasses ÷ 5, rounded up
beer_cases = beer_drinks ÷ 24, rounded up
```

- Soda water — 36–48 cans

- Cranberry juice — 2–3 large bottles
